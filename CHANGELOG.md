# Changelog

## 1.1.0

- Rebranded the package from `circular-page-transition` to `orbit-transition`.
- Added the primary `OrbitTransition` class API.
- Added the primary `createOrbitTransition()` factory.
- Renamed the React provider and hook to `OrbitTransitionProvider` and `useOrbitTransition`.
- Added deprecated compatibility aliases for the 1.0.x API.
- Updated README, demo, tests, and package metadata.

## 1.0.0

- First stable public API.
- Framework-neutral core with Vanilla link binding.
- React, React Router, and Next.js adapters.
- Cinematic, snappy, and soft presets.
- Edge-aware label recoloring.
- Phase lifecycle events.
- Reduced-motion support.
- Navigation re-entry protection.
- Responsive showcase.
- API contract and smoke tests.
- Node 18+ support.
- GitHub Actions CI and tag-based npm release workflow.
