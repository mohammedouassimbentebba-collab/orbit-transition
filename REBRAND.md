# Orbit Transition Rebrand

`1.1.0` is the official Orbit Transition identity release.

Primary usage:

```js
import { createOrbitTransition } from 'orbit-transition';

const transition = createOrbitTransition();
```

Primary class:

```js
import { OrbitTransition } from 'orbit-transition';
```

Deprecated compatibility aliases remain temporarily:

- `CircularTransition`
- `createCircularTransition`
- `CircularTransitionProvider`
- `useCircularTransition`

The npm package name is now:

```text
orbit-transition
```
